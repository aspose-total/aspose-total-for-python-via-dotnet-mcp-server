Aspose.Email MCP Server

MSGEMLPSTMBOXMHTML

Aspose.Email for Python via .NET enables reading, creating, converting, and extracting data from email files such as MSG, EML, PST, MBOX and MHTML.

Configure this server Official Aspose.Email page View source folder
Setup

Configure Aspose.Email in your AI client

Add one entry to your MCP host config — only the aspose-email key changes across clients.

{
  "mcpServers": {
    "aspose-email": {
      "command": "/path/to/servers/email/.venv/bin/python",
      "args": ["/path/to/servers/email/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-email": {
      "type": "stdio",
      "command": "/path/to/servers/email/.venv/bin/python",
      "args": ["/path/to/servers/email/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
