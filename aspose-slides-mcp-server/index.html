Aspose.Slides MCP Server

PPTXPPTODP

Aspose.Slides for Python via .NET is a library that enables Python applications to create, read, modify, merge, protect, and convert PowerPoint and OpenOffice presentations without requiring Microsoft PowerPoint.

Configure this server Official Aspose.Slides page View source folder
Setup

Configure Aspose.Slides in your AI client

Add one entry to your MCP host config — only the aspose-slides key changes across clients.

{
  "mcpServers": {
    "aspose-slides": {
      "command": "/path/to/servers/slides/.venv/bin/python",
      "args": ["/path/to/servers/slides/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-slides": {
      "type": "stdio",
      "command": "/path/to/servers/slides/.venv/bin/python",
      "args": ["/path/to/servers/slides/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json
