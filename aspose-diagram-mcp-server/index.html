Aspose.Diagram MCP Server

VSDVSDXVSXVTX

Aspose.Diagram for Python via .NET is a Visio file manipulation library that lets you create, read, write and export Visio diagrams in formats such as VSDX, VDX, VSD, PDF and various images.

Configure this server Official Aspose.Diagram page View source folder
Setup

Configure Aspose.Diagram in your AI client

Add one entry to your MCP host config — only the aspose-diagram key changes across clients.

{
  "mcpServers": {
    "aspose-diagram": {
      "command": "/path/to/servers/diagram/.venv/bin/python",
      "args": ["/path/to/servers/diagram/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-diagram": {
      "type": "stdio",
      "command": "/path/to/servers/diagram/.venv/bin/python",
      "args": ["/path/to/servers/diagram/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json

Troubleshooting

Common issues

SymptomFix
Tool returns an error because the file path includes directories instead of just a filename.Provide only the bare filename (e.g., "report.vsdx") and ensure the file exists in the ASPOSE_FILES_PATH directory.
The server reports that the input file cannot be found.Copy the required file into the folder configured as ASPOSE_FILES_PATH before invoking the tool.
