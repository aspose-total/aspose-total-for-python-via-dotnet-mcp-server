Aspose.ZIP MCP Server

ZIPRAR7zTARGZ

Aspose.ZIP for Python via .NET provides tools to create, extract, list, and manage ZIP, RAR, 7z, TAR, and GZ archives directly from a shared files folder.

Configure this server Official Aspose.ZIP page View source folder
Setup

Configure Aspose.ZIP in your AI client

Add one entry to your MCP host config — only the aspose-zip key changes across clients.

{
  "mcpServers": {
    "aspose-zip": {
      "command": "/path/to/servers/zip/.venv/bin/python",
      "args": ["/path/to/servers/zip/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-zip": {
      "type": "stdio",
      "command": "/path/to/servers/zip/.venv/bin/python",
      "args": ["/path/to/servers/zip/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json
