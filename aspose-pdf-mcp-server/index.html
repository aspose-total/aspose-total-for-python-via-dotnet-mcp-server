Aspose.PDF MCP Server

PDF

Aspose.PDF for Python via .NET lets developers create, convert, and manipulate PDF files programmatically, offering features such as text extraction, document encryption, and format conversion.

Configure this server Official Aspose.PDF page View source folder
Setup

Configure Aspose.PDF in your AI client

Add one entry to your MCP host config — only the aspose-pdf key changes across clients.

{
  "mcpServers": {
    "aspose-pdf": {
      "command": "/path/to/servers/pdf/.venv/bin/python",
      "args": ["/path/to/servers/pdf/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-pdf": {
      "type": "stdio",
      "command": "/path/to/servers/pdf/.venv/bin/python",
      "args": ["/path/to/servers/pdf/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
