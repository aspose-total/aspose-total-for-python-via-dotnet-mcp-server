Aspose.HTML MCP Server

HTMLMHTMLMD

Aspose.HTML for Python via .NET enables conversion of HTML, MHTML and Markdown files to formats such as PDF, DOCX, PNG, JPEG, XPS and more, and provides utilities to extract text, links and manipulate HTML elements.

Configure this server Official Aspose.HTML page View source folder
Setup

Configure Aspose.HTML in your AI client

Add one entry to your MCP host config — only the aspose-html key changes across clients.

{
  "mcpServers": {
    "aspose-html": {
      "command": "/path/to/servers/html/.venv/bin/python",
      "args": ["/path/to/servers/html/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-html": {
      "type": "stdio",
      "command": "/path/to/servers/html/.venv/bin/python",
      "args": ["/path/to/servers/html/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json

Common issues

SymptomFix
file not found or cannot locate input fileensure the input file is placed in the directory set by ASPOSE_FILES_PATH and reference it using only the bare filename
output file does not appear after conversionif you omitted the optional output filename, the server writes the result to the same ASPOSE_FILES_PATH directory with an auto‑generated name; check that folder for the new file
