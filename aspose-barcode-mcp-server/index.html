Aspose.BarCode MCP Server

QRCode128EANDataMatrixPDF417

Aspose.BarCode for Python via .NET provides APIs to generate and recognize a wide range of 1D, 2D and postal barcodes directly from Python applications.

Configure this server Official Aspose.BarCode page View source folder
Setup

Configure Aspose.BarCode in your AI client

Add one entry to your MCP host config — only the aspose-barcode key changes across clients.

{
  "mcpServers": {
    "aspose-barcode": {
      "command": "/path/to/servers/barcode/.venv/bin/python",
      "args": ["/path/to/servers/barcode/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-barcode": {
      "type": "stdio",
      "command": "/path/to/servers/barcode/.venv/bin/python",
      "args": ["/path/to/servers/barcode/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json
