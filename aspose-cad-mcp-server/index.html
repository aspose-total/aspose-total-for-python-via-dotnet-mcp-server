Aspose.CAD MCP Server

DWGDXFDWFDGNIFCSTL

Aspose.CAD for Python via .NET is a conversion API that lets developers render and convert CAD and BIM drawings (DWG, DXF, DWF, DGN, IFC, STL, etc.) to raster and vector formats such as PDF, PNG, JPEG, BMP, TIFF, SVG, and more, without needing any CAD software. It supports exporting whole drawings, specific layouts, or selected layers, and provides basic drawing metadata.

Setup

Configure Aspose.CAD in your AI client

Add one entry to your MCP host config — only the aspose-cad key changes across clients.

{
  "mcpServers": {
    "aspose-cad": {
      "command": "/path/to/servers/cad/.venv/bin/python",
      "args": ["/path/to/servers/cad/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-cad": {
      "type": "stdio",
      "command": "/path/to/servers/cad/.venv/bin/python",
      "args": ["/path/to/servers/cad/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json
