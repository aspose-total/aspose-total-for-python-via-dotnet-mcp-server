Aspose.3D MCP Server

FBXOBJSTLGLTFU3DDAE

Aspose.3D for Python via .NET is a feature‑rich API that lets developers read, write, manipulate and convert 3D file formats without needing any 3D modeling software. It supports many formats such as FBX, OBJ, STL, glTF, COLLADA and more, providing scene creation, mesh operations and rendering capabilities.

Setup

Configure Aspose.3D in your AI client

Add one entry to your MCP host config — only the aspose-3d key changes across clients.

{
  "mcpServers": {
    "aspose-3d": {
      "command": "/path/to/servers/threed/.venv/bin/python",
      "args": ["/path/to/servers/threed/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-3d": {
      "type": "stdio",
      "command": "/path/to/servers/threed/.venv/bin/python",
      "args": ["/path/to/servers/threed/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json
