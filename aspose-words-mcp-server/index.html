Aspose.Words MCP Server

DOCXDOCRTFODTMD

Aspose.Words for Python via .NET lets developers create, modify, convert, and render Word documents without needing Microsoft Office. It supports formats such as DOCX, DOC, RTF, HTML, Markdown, PDF, and more.

Configure this server Official Aspose.Words page View source folder
Setup

Configure Aspose.Words in your AI client

Add one entry to your MCP host config — only the aspose-words key changes across clients.

{
  "mcpServers": {
    "aspose-words": {
      "command": "/path/to/servers/words/.venv/bin/python",
      "args": ["/path/to/servers/words/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-words": {
      "type": "stdio",
      "command": "/path/to/servers/words/.venv/bin/python",
      "args": ["/path/to/servers/words/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json
