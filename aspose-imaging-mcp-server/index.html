Aspose.Imaging MCP Server

PNGJPEGTIFFBMPWebPGIFICO

Aspose.Imaging for Python via .NET is a library that provides advanced image processing capabilities such as loading, converting, resizing, cropping, applying filters, and adding watermarks without requiring external image editors. It supports many raster and vector formats and runs on both Windows and Linux platforms.

Setup

Configure Aspose.Imaging in your AI client

Add one entry to your MCP host config — only the aspose-imaging key changes across clients.

{
  "mcpServers": {
    "aspose-imaging": {
      "command": "/path/to/servers/imaging/.venv/bin/python",
      "args": ["/path/to/servers/imaging/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-imaging": {
      "type": "stdio",
      "command": "/path/to/servers/imaging/.venv/bin/python",
      "args": ["/path/to/servers/imaging/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
