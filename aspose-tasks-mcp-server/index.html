Aspose.Tasks MCP Server

MPPMPTMPD

Aspose.Tasks for Python via .NET enables programmatic creation, conversion, and inspection of Microsoft Project files such as MPP, MPT, and MPD.

Configure this server Official Aspose.Tasks page View source folder
Setup

Configure Aspose.Tasks in your AI client

Add one entry to your MCP host config — only the aspose-tasks key changes across clients.

{
  "mcpServers": {
    "aspose-tasks": {
      "command": "/path/to/servers/tasks/.venv/bin/python",
      "args": ["/path/to/servers/tasks/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-tasks": {
      "type": "stdio",
      "command": "/path/to/servers/tasks/.venv/bin/python",
      "args": ["/path/to/servers/tasks/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json
