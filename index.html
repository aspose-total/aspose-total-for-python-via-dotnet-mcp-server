Setup

Quick start

1. Clone the repository

git clone https://github.com/aspose-total/Aspose.Total-for-Python-via-.NET-MCP-Server
cd aspose-total-for-python-via-dotnet-mcp-server

2. Set up environments

servers\setup_all.bat
bash servers/setup_all.sh

3. Create a files directory

All tools read from and write to one directory you control, e.g. ~/asposefiles.

4. Configure your AI client

{
  "mcpServers": {
    "aspose-words": {
      "command": "/path/to/servers/words/.venv/bin/python",
      "args": ["/path/to/servers/words/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-words": {
      "type": "stdio",
      "command": "/path/to/servers/words/.venv/bin/python",
      "args": ["/path/to/servers/words/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}

Fully quit and restart your AI client after editing its config.

FAQ

Frequently asked

Does this work with Claude Desktop?

Yes. Add one entry per product to claude_desktop_config.json, set ASPOSE_FILES_PATH and (optionally) ASPOSE_LICENSE_FILE, then fully restart Claude Desktop.

Do I need a paid Aspose license?

No — every server runs in free evaluation mode by default. Set ASPOSE_LICENSE_FILE to your .lic file to remove evaluation limits such as watermarks.

Can I run only some of the 19 servers?

Yes. Pass specific product names to the setup script, e.g. setup_all.sh ocr words pdf cells slides, instead of setting up all of them.

Why does each product get its own virtual environment?

Each Aspose package is isolated in its own virtual environment so version conflicts between products are impossible and each server can be updated independently.
