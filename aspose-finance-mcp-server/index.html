Aspose.Finance MCP Server

XBRLiXBRLOFX

Aspose.Finance for Python via .NET is a library that lets developers create, read, validate, and convert XBRL, iXBRL, and OFX financial documents, with support for exporting to Excel.

Configure this server Official Aspose.Finance page View source folder
Setup

Configure Aspose.Finance in your AI client

Add one entry to your MCP host config — only the aspose-finance key changes across clients.

{
  "mcpServers": {
    "aspose-finance": {
      "command": "/path/to/servers/finance/.venv/bin/python",
      "args": ["/path/to/servers/finance/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
{
  "servers": {
    "aspose-finance": {
      "type": "stdio",
      "command": "/path/to/servers/finance/.venv/bin/python",
      "args": ["/path/to/servers/finance/server.py"],
      "env": {
        "ASPOSE_FILES_PATH": "/home/user/asposefiles",
        "ASPOSE_LICENSE_FILE": "/home/user/asposefiles/Aspose.License.File.Name.lic"
      }
    }
  }
}
// Same JSON shape as VS Code above — use the config path for your tool:
// ~/.cursor/mcp.json · Cline settings · Windsurf mcp_config.json

Common issues

SymptomFix
The tool returns an error because a full file path was supplied.Provide only the bare filename (e.g., "report.xbrl"); the server automatically prepends the ASPOSE_FILES_PATH directory.
File not found error when calling a tool.Copy the required input file into the ASPOSE_FILES_PATH directory before invoking the tool.
